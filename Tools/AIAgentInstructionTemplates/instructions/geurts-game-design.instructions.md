# Geurts Game Design Context Instructions

**Version:** 0.7.0

Read `GeurtsGameForgeDocumentation/AI_READ_FIRST.md` first. At session initialization, read `Docs/GameDesign/GameDesignManifest.md` once when it exists and re-read it only when its timestamp, hash, or version changes.

Never treat synchronized files inside `GeurtsGameForgeDocumentation/` as the target game's GDD. If relevant design context is unprovided, state the assumption before changing behaviour.
