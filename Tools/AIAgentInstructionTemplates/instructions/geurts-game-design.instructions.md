# Geurts Game Design Context Instructions

**Version:** 0.6.0

When a task affects gameplay feel, balance, progression, enemies, AI behaviour, levels, narrative, UX, accessibility, or player-facing content:

1. Read `GeurtsGameForgeDocumentation/AI_READ_FIRST.md`.
2. Read `GeurtsGameForgeDocumentation/GeurtsTechniques/GeurtsGameDesignDocumentationTechnique.md`.
3. Read the target project's `Docs/GameDesign/GameDesignManifest.md`.
4. Read every relevant project-specific design document identified by that manifest.

Never treat synchronized files inside `GeurtsGameForgeDocumentation/` as the target game's GDD.

If no relevant design document exists, state the assumption being made before changing behaviour.
