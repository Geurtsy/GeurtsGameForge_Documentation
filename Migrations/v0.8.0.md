
## Integration Changes

- Normal read-only repository checks and synchronization use public anonymous access by default.
- Game Forge Intelligence must reconcile supported integration-contract changes or report `PLUGIN_UPDATE_REQUIRED` without activating incompatible documentation.
- Integration contract v0.9.0 adds project-root `.gitignore` provisioning.
- The custom source is `GeurtsGameForgeDocumentation/GeurtsTechniques/GeurtsGitIgnoreTechnique.md`.
- The target is `<ProjectRoot>/.gitignore`.
- Setup creates only a missing target, preserves every differing existing target, and reports use of the versioned plugin default when the custom source cannot be used.

## Required Update

1. Update and validate the synchronized documentation through **Update Geurts Game Forge Documentation**.
2. Confirm the package reports v0.8.0 and integration contract v0.9.0.
3. Confirm the Git Ignore Technique v1.0.0 payload passes its marker, target, line-count, terminal-newline, and SHA-256 checks.
4. Update Game Forge Intelligence if it reports `PLUGIN_UPDATE_REQUIRED`.
5. Run the plugin's project `.gitignore` setup action. Existing project-owned content must remain unchanged.

No migration step may change Git tracking state automatically. Files already tracked by Git remain tracked until the user changes the index explicitly.
