# Historical Migration Note: Geurts Documentation v0.7.0

**Version:** 0.7.0
**Status:** Non-normative historical note
**Required package path:** `Migrations/v0.7.0.md`

## Historical Scope

Package v0.7.0 introduced an AI-first entry, a manifest index, machine-readable folder rules, create-if-missing GDD scaffolding, native-entry management, and categorized validation. It was an intermediate migration target for older v0.4.0 through v0.6.0 installations.

This file no longer defines an executable migration. Its former transport workflow and implementation details were removed or moved for v0.9.0. Do not recreate or invoke them from older copies of this guide.

## Preserved Historical Lessons

- The v0.7.0 package layout is superseded by the v0.9.0 target package.
- Native-entry migration was required to preserve user content, managed opt-out, and uncertain ownership rather than force replacement.
- GDD setup could create only missing scaffolds and could not invent or overwrite project design facts.
- Folder creation was create-only and never authorized deletion.

These observations are provenance only. They do not override current versions, paths, owners, or workflows.

Use `Migrations/v0.9.0.md` as the current transition checklist. Resolve all active package selection and subject ownership through `GeurtsTechniqueManifest.md`, and use the manifest-selected Game Forge Intelligence Technique when that integration applies.
